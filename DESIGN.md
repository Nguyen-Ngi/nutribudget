# NutriBudget design foundation

Use a cream workspace with a warm cream navigation header. Lime marks the current destination, overview welcome panel, and budget balance. Use citrus sparingly for selection and focus. Use local food imagery on Home and dish cards.

| Role | Token | Value |
| --- | --- | --- |
| Workspace background | `--surface` | `#f8f7f0` |
| Primary text | `--ink` | `#1c3027` |
| Secondary text | `--muted` | `#4e6056` |
| Dividers | `--line` | `#d8dfd3` |
| Navigation background | `--pine` | `#183c30` |
| Dark hover surface | `--pine-soft` | `#2d5142` |
| Selection and welcome | `--lime` | `#d9ebac` |
| Motif and dark focus | `--citrus` | `#f1d478` |
| Focus on light surfaces | `--focus` | `#9a471f` |

Use the serif display stack for page titles and the sans stack for controls and body text. Use labeled destinations with consistent line icons, a selected state, and visible keyboard focus. Navigation prioritizes Home, Meals, and Shopping. A Manage disclosure holds Budget and Pantry with their history. The header stacks above the page on small screens. At 39rem, each workspace row places its description below its label.

Budget setup groups related controls with visible labels and field-level feedback. Keep the balance prominent and expose budget management as a secondary disclosure.

Home pairs one remaining balance with a next-step action and a photo or labeled illustration from the dish catalog.
